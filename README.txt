SakayGuide - Commute Route Assistant (Metro Manila)

Paano buksan: i-extract ang zip, tapos i-double-click ang index.html sa browser.
Hindi kailangan ng server o install.

Note: Built-in na datos ang gamit (hindi live Google Maps). Estimate lang ang oras at pamasahe.
Ang fonts ay galing sa Google Fonts kaya kailangan ng internet para lumabas ang tamang font; may fallback naman kung offline.
